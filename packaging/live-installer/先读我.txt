# Posegraph Live 开发版：发给测试用户

1. 先在游戏插件管理器停用原来的 Posegraph（如有），然后退出游戏。
2. 完整解压本包，双击 Install-Live.bat。
3. 选已有后端的根目录（里面有 python 和 backend）；未安装过则选择英文路径的空目录，按提示完成基础后端安装。
4. 等待安装完成，再启动游戏。需要 Dalamud API 15 和 Brio。
5. 输入 /posegraph，点击视频按钮右侧的 Live 图标。

安装器自动备份旧后端源码、旧开发版插件和启动器配置，记录在所选目录的 live-backups。保存路径见 Live-installation.txt。
首次安装需要联网下载原版后端和运行环境，空间约 16GB。已有完整后端的 Live 更新包含离线模型和设备枚举依赖。
本包不会安装游戏、Dalamud 或 Brio。未找到启动器配置时，先运行一次启用了 Dalamud 的游戏，退出后重跑安装器。
请不要同时启用原版与本开发版，也不要用原版后端更新器覆盖 Live 源码。

校准：点校准后等待 2 秒，双手向前举，手指向上、掌心朝摄像头，完整入镜并稳定保持片刻。
本开发版仍可能有识别和姿势问题。第一次使用先备份 Brio 姿势；停止 Live 会尝试恢复启动时姿势。
不是正式稳定版；手指、坐姿、种族差异和游戏内视觉效果仍需测试。

恢复：退出游戏，将 live-backups 对应安装时间目录里的 src 复制回 backend/src；启动器配置的备份按同名文件放回对应 XIVLauncherCN 或 XIVLauncher 目录。
恢复整个配置会同时恢复备份时的设置，请先备份当前配置。如不熟悉这些操作，请把安装日志发给提供此包的人处理。

完整功能说明：docs/live.zh-CN.md。
