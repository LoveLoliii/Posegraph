# Live 实验版

从主窗口视频按钮右侧的广播图标进入。原图像、视频入口和流程保留。

## 功能

- 按名称选择摄像头，刷新设备；开始前校验设备身份，避免热插拔后编号变化误开其他设备。
- 实时预览、镜像显示、人脸框、身体和手指连线、接收帧率与后端耗时。
- 头部、头颈联动、三段脊柱、双臂、可见腿部、手腕和手指跟踪。
- 默认身体使用摄像头绝对姿态，复用原项目种族骨架、骨长适配和正向运动学。
- 手腕按角色参考掌面与真人掌面绝对对齐；手指弯曲按校准基准映射。IVCS 末节使用 `iv_*_c`，不存在的骨骼跳过。
- 表情复用视频的强度与眼睑、眉毛、嘴部、下巴、视线分项（0–2），采用相同的 0.7 基础折扣。首次复制视频设置，之后独立保存，也可手动重新复制。
- 额外张嘴上限与拉拉菲尔保守预设，同时约束下巴及嘴部范围。
- 暂停、两秒延迟校准、停止恢复；角色或外观改变时停止，避免向不同模型恢复旧姿势。

## 安装

需要同时更新插件和实际使用的后端源码。只替换 DLL，旧后端会返回 404。
保留现有一键包的模型、依赖和配置；Live 不需要替换原有 SAM 3D Body 权重。
更新同版本的后端 `src/posegraph` 源码后，使用该后端的 Python 安装摄像头枚举依赖：

```powershell
python -m pip install --no-deps cv2-enumerate-cameras==1.4.0
python backend/scripts/setup_live.py
```

下载脚本将官方 MediaPipe Face、Pose Lite、Hand Landmarker 模型放入后端的 `checkpoints/face`、`checkpoints/pose`、`checkpoints/hand`。
MediaPipe 安装沿用原项目面捕依赖流程，避免同时安装多个 OpenCV 发行包。三个 Tasks 模型须能在当前 Python 环境运行。

如果表情提示缺少数据，使用原项目 `/posegraph facedump` 导出角色的面部动画数据，再重新开始 Live。
启动后端时必须使用更新后的目录；停止 Live 后重启后端，并重新加载更新后的插件。

## 使用与校准

1. 进入 GPose，选择姿势正常的角色，停止视频及其他姿势编辑器。
2. 选择摄像头，按需启用“校准时匹配位置与镜头（之后固定）”，开始捕捉。
3. 点击校准，倒计时两秒后双手向前举起、手指向上、掌心朝摄像头。双手和身体手腕完整入镜，保持约 0.6 秒。
4. 系统等待双手姿势检查通过再重设基准；等待期间预览继续更新，角色保持当前姿势。检查覆盖双手完整入镜、手指向上、掌面不侧立和稳定性；单目关键点不能可靠区分所有掌心/手背情况，掌心朝向请按提示摆好。
5. 坐姿需要髋和膝可见。手部标记仅表示检测到手，是否成功匹配左右手以状态为准。
6. 停止或关闭面板恢复开始前姿势、场景位置与镜头。若开始时角色已经变形，恢复点也可能是变形姿势，应先在 Brio 恢复正常姿势。

暂停跟随不会关闭摄像头。停止会释放摄像头；后端正常响应的情况下，客户端断开后约八秒无请求也会释放会话。

## 自动构图

使用开始时角色位置与朝向作为场景基准，根据肩部中心及宽度估算构图。收集十五帧稳定数据后单次匹配位置和镜头，短暂收敛视线后固定，不再把每帧肩宽变化当作深度。
需要重新取景时再次校准。停止时恢复镜头参数和角色站位；退出 GPose 后不写入普通游戏镜头。

这是单目构图近似，不是现实米制定位，不会识别游戏椅子、座面或地形，也不支持持续全身走位或多人选择。

## 稳定性与限制

- 骨盆跟随髋部水平朝向，胸背相对弯转分配到三段脊柱。相对弯转限制为 60 度；已有目标的单次旋转突变限制为 20 度后再平滑。
- 肩髋退化、遮挡或非有限值时保持上次有效目标；脸部重获跟踪从已保持的朝向平滑恢复。
- 整身输出排除头部以下的通用下巴、头发和耳朵骨骼。整身与面部的模型空间姿势合并后一次导入，避免重复变换。
- 单目手指采用保守摆动限制，不推断轴向扭转，不是完整解剖约束求解。双手交叉、遮挡、快速转身和画面外部位仍可能出现错误。
- 当前为实验功能，不能把离线测试通过视为各族角色、IVCS 模型和游戏内视觉效果已经验证。
